================================================================================
                            О ПРОГРАММЕ
================================================================================

Steam Playtime Viewer — это настольное приложение с графическим интерфейсом,
предназначенное для получения и визуализации статистики игрового времени
пользователя Steam.

Программа взаимодействует со Steam Web API и отображает:
  - Список игр пользователя
  - Время в часах (десятичное) и минутах (полное)
  - Дату получения игры
  - Количество достижений
  - Время последнего запуска
  - Способ получения (платная/бесплатная/подарок)

================================================================================
                        СИСТЕМНЫЕ ТРЕБОВАНИЯ
================================================================================

Операционная система: Windows 7 и выше (также Linux, macOS)
Python: 3.8 или выше
Оперативная память: минимум 512 МБ (рекомендуется 2 ГБ)
Свободное место: 50 МБ
Разрешение экрана: от 320x480 до 7680x4320 (адаптивная вёрстка)

Зависимости:
  - PyQt5 >= 5.15
  - aiohttp >= 3.8
  - openpyxl (для экспорта в XLSX)

================================================================================
                           УСТАНОВКА
================================================================================

1. Убедитесь, что установлен Python 3.8 или выше:
   python --version

2. Установите зависимости:
   pip install PyQt5 aiohttp openpyxl

3. Запустите приложение:
   py -m main
   
   Или используйте start.bat (автоматическая установка Python при отсутствии)

   Или готовые сборки без Python:
   - main.exe (PyInstaller, 47 МБ) — основная, меньше памяти (~48 МБ в простое)
   - SteamPlaytimeViewer-nuitka.exe (Nuitka C++, 31 МБ) — компактная,
     но больше памяти (~83 МБ в простое). Функционально идентичны.
   Обе сборки самодостаточны: Python, pip-пакеты и докачивание
   чего-либо пользователю не нужны (проверено запуском в изоляции).

================================================================================
                       БЫСТРЫЙ СТАРТ
================================================================================

1. При первом запуске выберите язык интерфейса (15 языков).

2. Введите Steam API Key (32 символа).
   Кнопка "Ключ" открывает https://steamcommunity.com/dev/apikey
   Затем нажмите "Проверить" — зелёная подсветка означает успех.

3. Введите SteamID64 (17 цифр).
   Кнопка "Получить ID" открывает страницу аккаунта Steam.
   Затем нажмите "Проверить" — заполнится карточка профиля.

4. Нажмите "Посчитать время" в карточке профиля для загрузки игр.

5. Карточки окна можно переставлять: замок в нижней панели включает
   режим сетки, перетаскивание — за ручку "⠿", сворачивание — кнопка "–".

================================================================================
                       ОСНОВНЫЕ ФУНКЦИИ
================================================================================

АУТЕНТИФИКАЦИЯ:
  - Ввод и проверка Steam API Key
  - Ввод и проверка SteamID64
  - Валидация с цветовой индикацией
  - Скрытие/показ API ключа (кнопка-замок)

ПРОФИЛЬ:
  - Отображение Nickname пользователя
  - Статус: В сети / Не в сети / Занят / Играет
  - Общее время в играх
  - Компактная карточка фиксированной высоты (не тянется с окном)

СЕТКА ОКНА:
  - Карточки двигаются за ручку "⠿" в режиме сетки (замок внизу)
  - Сворачивание кнопкой "–", порядок запоминается
  - При растягивании окна растёт только таблица
  - На узких экранах (<900px) сетка складывается в одну колонку

ТАБЛИЦА:
  - Список игр с детальной информацией
  - Группировка серий (Warhammer, Borderlands): общее время по группе,
    раскрытие кликом по стрелке в колонке №
  - Колонка % — доля времени от всей библиотеки (не меняется при поиске)
  - Поиск по названию (максимум 14 символов)
  - Сортировка по любому столбцу
  - Пагинация (10/25/50/75/100/Все)
  - Подсветка первых 10 строк (зелёный) и следующих 10 (жёлтый)
  - Подсветка полностью полученных достижений

ЭКСПОРТ:
  - CSV (совместим с Excel)
  - XLSX (Microsoft Excel, Google Sheets)

НАСТРОЙКИ:
  - Светлая/Тёмная (OLED) тема
  - Выбор шрифта с предпросмотром
  - Размер шрифта от 8 до 72 pt
  - Горячие клавиши

АВТОСОХРАНЕНИЕ:
  - Профиль сохраняется через 3 секунды после загрузки
  - Кэш хранится 1 сутки

ЛОГИРОВАНИЕ:
  - Логи сессий создаются при каждом запуске
  - Ошибки сохраняются в отдельные файлы
  - Автоматическая очистка при превышении 10 МБ
