# Layout grid — верст-сетка

Статус: спека этапа. Числа-значения живут в `tokens/layout.json`; здесь — правила.

## 1. База и шкала

- Базовая единица: **4px** (`unit`).
- Все отступы, gaps, margins, радиусы — целые кратные `unit` из шкалы `space.*`.
- Типографские размеры (`font-size: 11px/13px` в подписях) сеткой не регулируются — они наследуют шрифт приложения; сетка регулирует только геометрию боксов.

## 2. Структура сетки

- **Dashboard**: 2 колонки, пропорции `3:2` (контент | профиль), gutter между ними `grid.gutter`.
- **Профиль**: под-сетка 2×2 (картинка | профиль / посчитать | общее время) + подписи `sub_*`.
- **Auth**: строки `api_grid` / `steam_grid`, 3 колонки (метка | поле | кнопки).
- **Диалоги**: одноколоночная сетка, кнопки — правый ряд.

## 3. ЖЁСТКО: отступы от краёв — абсолютные единицы

- `setContentsMargins`, `margin`, `padding`, `inset`, `left/top/right/bottom` — только `px` (в Qt; `rem/dp` — при порте).
- `%` в любом краевом отступе — **запрещён**. Единственное легальное `%` — доля колонки в `setColumnStretch`/`setRowStretch` (это пропорция, не отступ) и `text-align`/градиенты.
- Отрицательные margins — запрещены.

## 4. Направляющие (guides)

- Вертикальные: `edge.safe` слева/справа корневого layout; внутренние — границы колонок dashboard за вычетом `grid.gutter`.
- Горизонтальные: `edge.safe` сверху/снизу; границы карточек (`auth`/`profile` выровнены `_sync_card_heights`).
- Именованные направляющие фиксируются токенами `guide.*` и dev-overlay (ШАГ 6).

## 5. Правило fit

Элемент размещён корректно, только если:

1. его внешние границы совпадают с направляющей либо лежат внутри неё;
2. каждый внутренний зазор (`spacing`, `margin`, `padding`) — значение из шкалы `space.*`;
3. фиксированные minima (`setMinimumWidth/Height`, `setFixedSize`) — документированы в коде через токен или `component.*` и не выламывают соседние направляющие.

## 6. Правило out of bounds — ошибка лейаута

Любое из условий — ошибка:

- краевой отступ в `%` либо вне шкалы;
- граница элемента выходит за направляющую (переполнение колонки, клиппинг);
- элемент не привязан ни к одной направляющей (плавающий бокс без anchor);
- `addStretch` без пары (распорка, упирающаяся в пустоту вместо направляющей).

## 7. Как проверяется

- Dev-overlay (ШАГ 6): рисует направляющие поверх UI, подсвечивает out of bounds красным.
- Авточекер (ШАГ 6): парсит `setContentsMargins/setSpacing/...` и QSS, сверяет числа со шкалой и флагает `%` в edge-отступах. Запуск через shell, результат — в чат/лог.
- Ручной гейт: скрин-ревью с включённым overlay перед каждым релизом.
